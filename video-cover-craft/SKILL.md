# Video CoverCraft · 视频封面工坊

把用户已有内容或画面要求转成封面与完整提示词。默认风格库面向 AI 内容；其他题材按用户明确要求处理。先判断任务，只加载当前分支需要的细则，不顺序通读参考库。

## 1. 判断任务

| 用户意图 | 模式与动作 |
| --- | --- |
| 做封面、生成图片 | 默认 `image_and_prompt`：实际生图、验图，附完整提示词 |
| 只要图片 | `image_only`：生图与验图，不额外展示提示词 |
| 只要提示词、不生图 | `prompt_only`：设计与文字核对，不检测通道或 API Key |
| 反推已有图的提示词 | `prompt_from_image`：查看图片，写近似复现描述，不自动改版或生图 |
| 诊断旧封面 | `diagnosis_and_prompt`：先看旧图，给评审、修改顺序与改版提示词；明确只诊断则 `diagnosis_only` |
| 诊断后重做 | 完成诊断后继续已授权制作，不另加建议批准环节 |
| 只看风格或只拟标题 | 完成浏览/文案任务，不触发生图或制作问卷 |

仅提示词、已有图提词和未授权改图的诊断不创建虚构的成图或验图记录；“完整预览”不改变上述任务意图。

## 2. 只补实际缺项

- 视频脚本、视频描述、封面描述任一种即可，也可组合。内容事实约束主题，明确画面要求约束设计；最新要求优先。缺核心主题/主体或存在实质矛盾时才补问，不强求完整脚本。
- 新封面、其完整提示词或整体重设计的**创作方式未明确**时，主动问「这次按当前基础风格（常规）生成，还是用创意风格重新设计？」并等待回答，不能默认为常规后定稿。与尚缺的画幅、人物合并问一次；快速交付也适用。已明确基础/创意、选定内置风格、授权「风格你决定」或沿用本轮选择时不重复问。单给参考图、配色、材质或说「直接做」不等于选择创作方式。局部修改、提词、只诊断/浏览/拟标题不新增此问。
- 新封面及其完整提示词定稿前确认**画幅与人物**，缺项合并问一次。只说横版采用 16:9、竖版采用 3:4；已有选择不重复问。只有明确授权两项由 Agent 决定且无需询问，或有获授权的长期默认，才能自行采用；“直接做”不等于回答两项。已有图提词/诊断沿用可判断的设置。
- 指定封面文案逐字采用；未区分用途的“标题”仍作封面标题。视频标题单独记录，不自动入画；没有视频标题也可继续。未给封面文字可拟写，要求无字则全图无字，不追加标题批准步骤。
- 未指定方案数做一套，每个「方案 × 画幅」独立出图，横竖版重新构图。有人物未指定照片时可用原创角色；风格参考中的脸不是身份素材。无人物包括无手、人形机器人、拟人角色或剪影。
- 技能目录存在 `user-preferences.json` 时读适用设置；只有明确免问的长期默认视为已回答，本期要求优先。读取/保存偏好细则仅在应用配置或用户要求长期记住时加载；单次反馈不自动保存。

## 3. 设计与执行

1. **设计**：按已明确的选择采用当前基础风格（常规，`regular`）或创意（`creative`）；获授权自行决定时通常从基础开始。提炼一个主要关系，安排主体、构图、配色、字形、质感与文字层级，记录锁定、继承和重新设计项。创意按意图延展或探索，主动变化构图/主视觉。局部反馈只改该范围；全部不喜欢时退出原菜单探索，保留内容、文案、画幅、人物和必要素材，用户明确仍要基础风格则服从其限定。
2. **选择风格/素材**：要求先看再选时，可与创作方式澄清同轮展示真实样图并等待；已指定参考或授权自主选择具体方向时不重复开菜单。基础制作未定具体风格可推荐最多三种，B/S 编号不成为额外必答项。图片先实际查看，指定图不可访问先取得原图，不虚构观察。分清风格、构图、身份、产品/界面和修改目标；选为图像条件的图须实际传入。创意探索可省略未要求使用的旧风格图，必需身份/准确界面素材不能省略。
3. **执行对应分支**：制作/提词先确定文字清单。仅提示词直接编写自足正文；实际生图才读取通道细则，优先可调用的 GPT Image，其次平台原生工具。用户明确通道选择优先，仅存在 Key 不启用 API。遵照当前工具参数，记录实际通道与已知型号，未知不猜；无能力时说明未生图。修改以本轮成图为目标，不把文字重画称为定点编辑。
4. **验收并交付**：成图完成下方核心检查，按交付深度组织产物。每张图的可移植提示词整合最终目标与有效修改，不只给局部编辑句。真实人物/准确界面所需附件单列；普通风格完整展开，不依赖 B/R 编号、本机路径或旧对话。

## 4. 两种交付深度

深度只决定已授权成图的附加产物，不增加必答问题，也不改变创作方式或任务模式。

| 深度 | 选择与交付 |
| --- | --- |
| **快速交付 `quick`（默认）** | 原图或用户要求的格式、对应完整提示词（除仅图片）、简短检查与限制说明。检查完整图和约 320px 小图；不默认做双格式导出、对比 HTML 或列表预览 |
| **完整预览 `full`** | 用户要求完整预览/文件包、列表预览或缩略图对比时采用。在同一核心检查上增加 PNG/JPEG、缩略图对比页、浅/深列表及 320/168/120px、模拟遮挡和边缘裁切检查；另有灰度/模糊/区域遮盖、图上批注与修改单导出、新旧版本对比 |

只指定一种格式/尺寸可在快速流程补足；快速交付同时点名某项附件时补那项，不扩成整套。仅提示词/提词/诊断仍按各自分支交付，不为预览生成新图。文件记录与预览操作见当前分支细则。完整预览中的诊断只影响显示；批注可导出交回本技能，实际改图仍遵从本轮授权与锁定项，人工复核不替代核心验图。改图后的预览明确指定当前新版与上一版，默认在新版上继续批注；复制修改单只包含当前选中图片的批注，历史批注留在版本对比与完整备份中。

## 5. 核心验图：两种深度都保留

实际查看每张**完整图与约 320px 小图**，记录可见依据：

- 主副标题、品牌、标签、数字与标点逐项核对，扫描背景杂字、水印；无字请求检查全图没有意外文字。
- 主体与关系对应本期内容/画面要求，不添加无依据功能、结果或数字；有视频标题时一起核对共同表达。
- 人物模式、身份素材、实际比例和数量正确；比例不符用生图工具重新构图，比例相符才等比调整，不拉伸或机械裁切适配。
- 小图主标题与主视觉清楚，对比足够，关键文字、脸、产品不贴边或被裁掉；准确界面用真实素材，不把生成示意称为真实截图。
- 用户锁定项与本轮设计目标落实；创意允许变化的外观偏离旧图不判失败，重复被拒绝的结构仍需修正。

记录 `pass` / `needs_fix` / `uncertain` / `not_checked`。未实际查看、看不清或缺少能力的项目如实标明，生成预览文件不等于已验收。快速交付中未请求的列表检查记 `not_checked`，不因此判核心验图失败。

错字、主体或画幅错误优先定点修正并复核全图，默认最多追加两轮；仍有问题交付候选并说明。纯提示词只能核对规格。扁平图片不承诺自动分层，可编辑文字仅在用户要求时走额外排版。
