# 把参考图变成可执行的设计规格

只描述看得见的特征，区分观察与推测。不能凭最终封面判断作者使用了哪个模型、软件，也不能把点赞数解释成点击率。

## 图片角色与优先级

给图片分配编号和明确角色，例如：

- R1：封面风格参考，提供黄蓝配色、粗标题和斜向色块，不沿用人物、文字。
- R2：本期人物照片，唯一身份依据，保留脸型、发型、眼镜等。
- R3：本期软件截图，内容素材，应保持可辨识的布局和品牌。

用户的具体要求优先于参考图；所选主参考只约束本轮明确借用或用户锁定的特征。用户要求贴近右文左图的参考时保持相应节奏；用户要创意重设计时可以改变布局。用户选无人物，不能因为 R1 有人物就生成同一张脸。按 [creation-modes.md](creation-modes.md) 区分锁定、继承与重新设计项，观察到的原图特征不自动成为锁定项。

## 观察表

| 维度 | 要提取的具体内容 | 转成提示词时的表达 |
| --- | --- | --- |
| 构图 | 标题/主体位置、大致面积、视线/手势方向、前后遮挡 | 标题占上部约三分之一，主体在下部偏右；比例是目测而非精确测量 |
| 配色 | 底色、强调色、文字色及面积关系 | 深蓝黑占主体，黄色只用于标题重点；颜色代码仅在可靠测量时写 |
| 标题 | 粗细、字形类别、字距、行数、描边、投影、倾斜 | 两行紧凑粗黑体，白字深色描边，关键词用黄底黑字；不声称识别了准确字体名称 |
| 主体 | 人物/设备/界面/插画、大小、动作、摄影或绘画质感 | 用笔记本与时间线面板接替原人物，保留大主体与标题的关系 |
| 背景 | 室内、渐变、科技空间、色块、网点、留白 | 保留暗色景深与边缘光，减少背景文字 |
| 层次 | 标题、主体、界面、装饰的亮度与位置关系 | 标题最清楚，主设备次之，背景面板压暗 |
| 情绪 | 克制、惊讶、教程感、漫画夸张等可见线索 | 漫画式夸张但不增加无关情节 |
| 排除项 | 水印、原作者名字、平台 UI、原文案、无关产品 | 不输出点赞图标、播放量、底部导航和原账号标记 |

设计摘要可写成：

```text
主题：AI 自动剪辑工作流
参考角色：R1 为主风格；R2 为真实软件素材
继承：深蓝底、白黄两级大标题、设备透视、轻微边缘光
替换：原人物改为笔记本与时间线；原文字改为本期标题
人物：无人物
文字：主标题「AI 自动剪辑」；副标题「完整工作流」
横版：标题左上，设备右侧，时间线延伸到中下部
竖版：标题上部，设备中下部，时间线成为下部背景层
排除：原账号、水印、平台 UI、任何人形
```

这个例子是构图说明，不是对原对话中未提供像素的参考图的真实观察。

## 多图与重复使用

先检查所有可见参考，再选择适合当前方案的关键图。多张参考可以分为真人大字、软件教程、科技合成、漫画、轻包装、编辑海报等组；分组必须以当前实际图片为依据。通常每张成图用一张主风格图和必要的主体素材即可，不要求固定数量。

每个方案单独标注所用参考；不同组可以形成不同方案，同一方案不要同时服从冲突的标题密度和画面质感。内置工具有引用数量限制时，按工作流处理，不声称已将全部图片交给模型。

保存设计摘要可帮助同系列复用，但不能替代必需的图像条件输入。需要身份、准确产品/界面或用户指定的原图参考时，下次调用仍需有可访问的关键图片；创意探索可依据文字重新构思，记录没有传入旧风格像素，不称为精确复现。

用户没有指定原图而按风格选用，或允许自由设计时，可从黄蓝冲击、蓝黑科技、白橙清单、彩色漫画、极简编辑、发布会实测、双阵营对比、未来办公、矩阵控制室、立体概念十种 AI 基础方向中选择；具体分支见 [style-catalog.md](style-catalog.md)。它们不覆盖用户指定参考。

常规与创意延展选少量可识别特征，按内容调整场景、对象关系或构图；创意探索可以重建表达结构，无须保持原图可识别性。旧参考和新参考都有具体延展建议，不只换原图标题。配色也可以独立延展：原图颜色是观察信息，用户未锁定时可自主换色并借鉴网上搭配，见 [color-palettes.md](color-palettes.md)。设计摘要区分观察、所选特征和本期新设计，避免把提议说成原图事实。
