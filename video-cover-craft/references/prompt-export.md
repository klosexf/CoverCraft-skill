# 可交给其他生图 AI 的封面提示词

用于默认的图片＋提示词交付、仅提示词、已有图提词，以及旧图诊断后的改版提示词。区分**实际调用记录**和**可移植提示词**：前者记录当前工具如何生成或修改，后者让不了解本技能、原对话和本机路径的 AI 也能理解完整画面。

新设计的仅提示词任务同样在创作方式缺失时先问当前基础/创意，合并尚缺的画幅、人物并等待回答；规则见 [creation-modes.md](creation-modes.md)。已有图近似复现或未授权重设计的诊断不新增创作方式问题。

## 根据模式确定依据

- **`image_and_prompt`**：先完成生图与可执行的修正，查看最终交付图；结合最终画面、设计摘要和文字清单整理提示词。将初始要求与历次有效修改合为一次从零生成的描述，不只写“把副标题改成……”或“其余不变”。每个方案和画幅独立编写，不把横版提示词仅改比例后交作竖版。
- **`prompt_only`**：使用已经明确的内容、画面要求、画幅、人物和风格规格直接编写；需要的文字清单照常建立。无需先生成样图、检测图片通道、读取 API Key 或配置外部模型；只做文字与设计一致性核对。
- **`prompt_from_image`**：先查看用户指定的实际图片，读取尺寸或按可见画面判断比例，再提取主体、布局、配色、文字和质感。已有图中可判断的设置直接沿用，不额外索取视频脚本或询问原模型、种子。不能从像素找回真实原始提示词、模型或种子，只交付基于可见特征的近似复现描述。
- **`diagnosis_and_prompt`**：先按 [cover-diagnosis.md](cover-diagnosis.md) 诊断旧图，以其可见规格、用户要求和优先修改项编写完整改版目标，依据标为 `redesign_spec`，不能称为旧图复现或新成图。关键文字待确认时先交付诊断和缺项，取得原文后再定稿；`diagnosis_only` 不要求编写提示词。

图片不可访问时先取得对应图片，不能依据附件占位符虚构特征。重要文字看不清时请用户补充该文字；可先交付不含未确认文字的画面提示词，说明文字部分待补。颜色与主体占比是观察近似，不编造精确字体名、品牌、功能或数字。用户要求修改已有图时，以其最新要求覆盖可见特征，并说明输出针对修改后的目标画面。

成图仍有未修好的错字、错误主体或比例时，在复制块之外列明差异；提示词保留用户规定的正确文字和目标要求，不能称其已与错误成图完全一致。没有实际查看最终图时，将依据标为设计规格，并说明尚未按最终像素核对。仅在生成前交付的提示词也属于设计规格，不冒称成图反推。

## 完整提示词要写什么

默认用中文自然语言；用户要求英文时可用英文描述画面，图中中文标题仍逐字保留，不自动翻译。每份正文独立包含适用的项目：

1. **用途与画幅**：一张独立视频封面、实际比例、横竖方向；目标尺寸可另列为建议设置，不把它当成对目标工具原生能力的保证。
2. **主体与关系**：具体对象、数量、动作、场景，以及流程、接力或对比等关系。内容事实与用户意图优先，不能只给标题加“高质量”。
3. **构图与层级**：主体和标题的位置、大小关系、前后遮挡、留白及边缘安全；改画幅时分别安排。
4. **视觉语言**：材质、摄影/插画/纸雕等质感、线条、光线、背景、情绪；配色写清背景、文字、强调和辅助色各自用途。
5. **人物要求**：无人物时排除真人、虚拟人、肖像、手、人形机器人、拟人角色和人形剪影；有人物时写身份素材来源或原创角色要求，不借用风格参考中的脸。
6. **图中文字**：逐字引号引用主标题、副标题和必要标签，写断行、大小层级、位置、颜色、描边；只准出现文字清单中的内容。视频标题不自动入画。无字时明确全图无文字、数字、品牌与标签，背景文档、屏幕和道具也无字。
7. **限制**：与本轮相关的禁止元素、杂字、水印、平台界面、拼图、裁切和未经支持的宣传数字。关键限制写进同一正文，不依赖目标 AI 支持负面提示词字段。

提供视频标题时按 [title-cover-alignment.md](title-cover-alignment.md) 核对它与封面共同表达的内容，将必要关系落实为主视觉；视频标题仍是语境，不自动加到图中。缺少视频标题时继续正文交付，不为联合检查制造缺项。

不使用“按 B03”“沿用 R10”“参考上图”“与上一版相同”等缺失上下文的指令；把实际选用的视觉特征展开。正文不含技能安装路径、当前工作区路径、`referenced_image_paths`、`num_last_images_to_include`、API Key 或宿主调用代码。

未指定目标 AI 时不追加平台问题，也不默认塞入某平台的 `--ar`、`--v`、采样器、CFG、种子或权重语法。用户明确指定目标平台时，在通用正文之后按已核实的实际能力补充可选设置；无法核实时保留自然语言版本，不猜参数。负面提示词可按用户要求单列，但核心约束仍保留在正文中。

## 参考图与素材怎么迁移

风格参考能用具体描述表达时，默认正文自足，不要求用户把本技能图库导入其他 AI。可以在正文之外列可选参考，注明不上传也能依据描述生成近似风格。

需要保留真实人物身份、真实产品外形或准确软件界面时，文字不能代替像素。列出用户必须另附的真实文件或当前附件，以及角色、上传顺序与约束。正文可写“附件 1 为人物身份照片，附件 2 为软件截图”，但交付旁边必须给出对应素材清单；没有附图时不得声称能保持同一身份或精确界面。不要静默换成虚拟人物来掩盖缺少身份素材。

以最终封面作为参考可提高相似度，但只在用户要求或确有需要时列为可选/必要附件；普通可移植提示词要能描述完整画面，不只写“重做附件”。用户指定另一张参考时使用那张图，不能擅自换成图库图片。

## 交付与保存

单方案直接返回一份独立可复制的提示词正文；多方案逐项标注方案和比例。素材清单、建议画幅设置、限制说明放在复制块之外。简短说明不同模型可能改变排版、中文准确性和细节，不承诺逐像素复现。不要只给下载链接而省去用户可以直接复制的正文。

有可写工作区时，将文字产物放在用户指定位置，或 `outputs/video-cover-craft-<日期或主题>/`；无文件写入能力时直接在对话交付并说明未保存文件，不因此中止提示词任务。

- `portable-prompt-<方案>-<画幅>.txt`：仅保存可复制的完整正文，一份对应一个方案和画幅；修改最终图后同步更新。
- `design-brief.md`、`text-spec.json`：沿用主流程的设计依据和逐字文字规格；仅图片反推时 `input_modes` 包含 `cover_image`，无依据的视频标题留空。
- `prompts.json`：记录 `output_mode` 与各份提示词的 `id`、`aspect`、`people`、`prompt_file`、`source`（`design_spec` / `final_image` / `existing_image` / `redesign_spec`）、`source_image`（没有则 `null`）、`required_attachments` 和 `limitations`；以实际依据填写。真实素材路径可记在元数据中，但不混进通用复制正文。
- 仅实际生图时保存工具调用的 `prompt-*.txt`、`generation.json` 与成图 `review.json`，二者不替代 `portable-prompt-*.txt`。仅提示词或已有图提词不新建虚构生图与验图记录，不跑图片导出或列表预览，也不称文字核对为视觉验收通过。

旧图诊断的实际观察另存 `diagnosis.md` / `diagnosis.json`；仅诊断或改版提示词不新建成图验收记录。实际生成改版后，`output_mode` 改为所选制作模式，提示词 `source` 根据是否已看最终图采用 `final_image` 或 `design_spec`，保留旧图诊断来源以便区分。

交付前逐项核对内容、构图、画幅、人物、逐字文案、参考依赖和禁止项，确认没有遗留本机路径、技能编号依赖或局部编辑语句。`image_only` 不要求另写可移植提示词；以后用户补要时，再据最终图整理。

## 一份无需附件的通用正文示例

以下针对一套竖版无人物教程封面，实际使用时以本期输入替换：

```text
生成一张独立的竖版 3:4 中文视频封面。主题是先讨论清楚需求，再整理开发说明，最后交给开发工具实现。完全无人物，用文档与设备表达三个对象的接力关系。

画面采用有景深的立体概念插画：深青色书房背景，暖橙色柔和光照亮右下方打开的笔记本电脑。左侧中部漂浮一块聊天面板，中央放一张开发说明纸页，柔和的发光箭头依次连接聊天面板、纸页和电脑。三个主体清楚分离，电脑最突出，背景低对比。面板和文档只用无字线条表达信息，屏幕保持无字，不展示真实软件功能。所有主体完整可见，四周留安全距离。

上方约三分之一安排大标题。主标题逐字为「先聊清楚，再开发」，分两行：第一行「先聊清楚，」，第二行「再开发」；使用紧凑粗黑体、奶油白字、深青细描边，关键字用暖橙强调。主标题下方以明显较小字号逐字写副标题「需求 → 说明 → 实现」，保持清楚间距。标题最醒目，主体次之，光效不遮挡文字。

只出现上述主标题和副标题，不加品牌、数字、口号或其他文字。无真人、虚拟人、脸、手、人形剪影、人形机器人或拟人角色。无水印、账号名、平台播放或点赞界面。单张完整封面，不做拼图或分屏，不裁掉标题和设备，不添加效率倍数或节省比例。
```

建议设置：3:4；目标导出尺寸可为 1080 × 1440，按目标工具支持的设置选择。此例无需图片附件，也不依赖本技能。
