# 新增横版参考：14 张独立风格档案

本库来自用户追加的两张真实截图：R12 含四张封面，R13 含两行五列、共十张封面。每张封面分别命名、提炼并给出延展。下文的「原图观察」来自可见像素；「延展」是本技能提出的新设计方向，不是对原作者制作方法的判断，也不是已生成的样张。

原截图保持未改动，位置映射见 [reference-manifest.json](../assets/reference-manifest.json)。**调用时查看原图，将原图实际传给选定生图工具，并指定只参考目标单元格。** 单独的档案不等于已裁出清晰单图。坐标仅用于定位原截图中的大致区域，不作为最终裁切尺寸或画面安全区。

## R12：实测与观点类

[查看 R12 原图](../assets/user-references/ref-12-horizontal-review-strip.png)。它的四张图都以深色工作空间、近景人物和醒目标题组织画面；下文各自的结构区别比统一套一个「科技风」更有用。

### R12-01 · 深色发布会实测

**原图观察**：黑灰与暖金工作室；左上白色斜体英文和中文标题，右上白色型号与金色版本数字；人物在中间偏右，前景手势放大；小品牌标记在左下背景。左右文字共同围绕中心主体。

**保留与调整**：保留白金文字、暗室景深和前景主体；标题分区依本期信息重新组织。原模型版本与品牌标记不自动沿用，实测结论必须来自脚本。

- **延展 A「发布信息与体验结果」**：左右两个标题区分别表达发布信息与本期体验，主设备连接两区。适合脚本确实含发布与实测两部分时。
- **延展 B「重点功能实测台」**：改成一个主设备、一个功能近景，保留白金字与室内质感；缩减英文大字，让功能动作成为视觉中心。

**无人物 / 竖版**：用本期产品或大设备承接前景重量，不补上无主的手。竖版把两组标题合并成上下主次层级，产品放中下部，避免照搬左右各一大段。

### R12-02 · 冷暖双阵营对比

**原图观察**：左蓝右橙的两块光域；顶部粗斜体白蓝字与橙字形成对照；人物居中，左右手各持一种工具图标。左右对象大小接近，中心人物将两边联系起来。

**保留与调整**：保留冷暖分区、两对象与同等视觉重量。根据脚本决定它们是比较、协作还是接力，不因对比画面自动判胜负。

- **延展 A「两工具接力」**：蓝区负责输入或规划，橙区负责执行或产出，用一条动线连接；适合脚本中的工作流。
- **延展 B「同任务双方案」**：用相同任务的两种处理方式做左右对照，中心放共同输入或比较指标，避免只摆两个图标。

**无人物 / 竖版**：用两个产品或面板和中心任务卡取代人物与手势；竖版可上下两区或斜向分区，保持两方同等清楚。与基础分支 B02-C 相近。

### R12-03 · 勾叉观点辨析

**原图观察**：上方白字加黄字疑问标题；深色工作室；中心人物左右举绿色勾与红色叉；背景有较暗的信息图与软件面板。符号是核心叙事，而非纯装饰。

**保留与调整**：保留明确的两种判断和大问题标题。只有脚本给出支持与反对、正确与错误或适用与不适用时才用勾叉，不给尚未测定的产品凭空加结论。

- **延展 A「误区与正确做法」**：两张任务卡各表达一个具体做法，勾叉贴近相应内容，中心标题点出问题。
- **延展 B「适用条件分界」**：改为两种使用条件的边界图；若结论非对错，可改成问号与条件标签，保留观点辨析结构。

**无人物 / 竖版**：两张内容卡承接原手举符号，不能生成悬空人手。竖版标题在上、判断卡上下或短左右排列；关键条件比背景小字优先。

### R12-04 · 产品实测问答

**原图观察**：左侧白色结论式标题加黄色疑问；右侧人物展示白色产品标记；深灰背景里有产品字样和压暗的软件界面。提问与展示产品形成左右呼应。

**保留与调整**：保留白黄问答标题和产品展示关系。问题可以开放，但画面不能把未经验证的额度、性能或价格结论当作已经成立。

- **延展 A「问题与证据台」**：一个醒目问题对应一个与脚本相关的测试对象或结果卡；减少背景 UI，突出证据的具体对象。
- **延展 B「卖点与使用条件」**：主产品旁搭配一个关键使用条件，让画面表达它在什么情况下有用，而非泛泛夸产品。

**无人物 / 竖版**：放大主产品或设备替代人物，相关证据卡置旁边；竖版依次安排问题、产品、条件。与 B02-B 产品实测台相近。

## R13：场景与概念类

[查看 R13 原图](../assets/user-references/ref-13-horizontal-creative-gallery.png)。只参考各格内部的封面；日期、封面下方的视频标题、截图空白不是设计的一部分。

### R13-01 · 太空夸张体验

**原图观察**：黑色太空与灰色月面；顶部黄色宽字距标题；穿太空服的人物和卡通角色；两侧拇指靠近镜头，透视夸张。黑黄文字与巨大前景手势共同制造冲击。

**保留与调整**：保留黑黄、远近尺度和空间感；太空是一种场景比喻，只有它有助表达本期体验或探索时才用。

- **延展 A「双设备登月对照」**：两种工具以不同探测设备呈现，脚本中的任务变成共同探索对象；不暗示任何一方胜出。
- **延展 B「地面到太空升级」**：前景是现实任务，远景是扩展后的工作空间，以尺度变化表达能力范围；不虚构量化提升。

**无人物 / 竖版**：使用设备、非人形探测器与任务物件，排除太空人、手、脸。竖版上方黑黄标题、下方一个大近景对象，少放并列主体。

### R13-02 · 多臂工作助理

**原图观察**：白灰浅背景；左侧大黄字黑描边「帮你干活」；中部人物与机械躯干，多条机械臂展示任务屏幕和工具；下方笔记本压住前景。亮色标题与多任务陈列形成信息结构。

**保留与调整**：保留浅底、黄黑字和任务环绕关系。每个工具代表脚本里真实的一类任务，不把「多臂」当作没有依据的无限能力。

- **延展 A「任务分拣台」**：任务从一个入口进入，分派给少量不同功能模块，输出结果在前景汇合。
- **延展 B「技能环绕工作台」**：主设备居中，相关技能卡按场景环绕；以卡片关系表达协作，不堆满装饰窗口。

**无人物 / 竖版**：机械臂从桌面或设备底座伸出，不生成带人脸的机器人；也可完全改为功能卡。竖版任务卡分布两侧，主设备保持最大。

### R13-03 · 魔法入门教程

**原图观察**：蓝天与云层、速度感；上方白色英文名称与黄色教程字；左下巨大亮边应用图标；右侧人物穿魔法装束并挥动道具。图标、动作、标题构成教程引导。

**保留与调整**：保留蓝色空间、白黄字和放大的工具标识；「魔法」表达学习路径或工具作用，不能代替具体内容。

- **延展 A「学习路线卷轴」**：用卷轴、路标和少量关卡表达脚本的入门顺序；标题与终点成果形成呼应。
- **延展 B「工具魔法书」**：一本展开的教程书将本期工具与成果联系起来，保留发光图标，避免多处小字。

**无人物 / 竖版**：书、路线图或设备承担主视觉，排除魔法师与人手。竖版将图标和教程对象上下排列，标题留出独立空间。与 B04-C 冒险教程可相互参考。

### R13-04 · 航海全解教程

**原图观察**：蓝色海天/宇宙质感；顶部黄色英文工具名与两侧白色大字；前景船舵、人物、帆船与卷轴地图。空间透视与导航道具表达「带路」感。

**保留与调整**：保留蓝黄白标题、航线和导航道具。原图的「全解」不自动成为本期承诺；脚本只是单个技巧时采用相应标题。

- **延展 A「工作流航线图」**：用航线的起点、关键节点与终点映射任务过程，工具成为导航对象。
- **延展 B「工具舰队协作」**：少量船只代表脚本中的工具分工，共同航向成果；只有内容确有多工具协作时使用。

**无人物 / 竖版**：用船、导航图与船舵取代人物，不出现驾驶者或人手；竖版一条纵向航线足够，减少横向铺满的船只。

### R13-05 · 矩阵控制室

**原图观察**：暗色宽阔室内，蓝青发光的重复格阵；格子里有红色虾形对象；黄色标题在上，人物在下中部张开手臂。重复单元制造规模感，中心主体提供焦点。

**保留与调整**：保留暗室、青色矩阵和一个明确焦点。虾是原选题的对象，不是通用装饰；本期任务替换成对应模块，数量不表达未经证实的规模。

- **延展 A「任务调度矩阵」**：用少量任务单元表现不同工作，突出正在处理的一格与输出结果。
- **延展 B「单元放大诊断」**：背景矩阵中的一格放到前景，展示一个具体问题或设置；适合排错、配置与教程。

**无人物 / 竖版**：前景控制台或放大任务卡代替人物；竖版把矩阵收成窄网格，标题与重点单元保持清楚，避免满屏小字。

### R13-06 · 云端理想世界

**原图观察**：明亮蓝天、白云与白色柱廊；黄色粗标题；中心人物、羽翼、光环及周围小角色。对称空间与轻盈道具表达理想化体验。

**保留与调整**：保留明亮蓝白、黄色标题和云端空间感；翼、光环、小角色不是必需元素。只在脚本表达轻松、理想化工作方式时采用这一比喻。

- **延展 A「云端工具岛」**：功能与成果分布在少量云台或浮岛上，以明确路径连接，形成轻盈的工作空间。
- **延展 B「轻量云端工作台」**：只保留一张云端桌面、主设备和成果，减少繁复幻想道具。

**无人物 / 竖版**：云台、设备与任务物件即可，排除天使、面孔和人形角色。竖版减少对称两侧装饰，突出一条向成果推进的动线。

### R13-07 · 未来悬浮办公

**原图观察**：蓝紫云海；顶部巨大黄色「未来办公」；中心人物周围是弧形青蓝全息面板与悬浮设备。环幕和纵深同时表达工作环境。

**保留与调整**：保留蓝紫云海、环幕透视和黄字，不照搬原人物。面板内容围绕脚本任务，不能用模糊图标冒充实际功能。

- **延展 A「环幕工作台」**：主设备面向环形的输入、过程与输出面板，以一个任务组织环幕。
- **延展 B「模块化办公室」**：若干工作模块沿同一空间路径串联，突出分工或协作，替代四处悬浮的装饰屏幕。

**无人物 / 竖版**：放大桌面、键盘或任务模块作主角，不生成空中办公室里的人；竖版环幕收成半环，主设备放下方。

### R13-08 · 国风专家模式

**原图观察**：黄色上方大字；灰白传统服饰、帽饰与扇形/笔状道具；现代笔记本与室内窗景并置。传统角色与现代工具的反差是主要表达。

**保留与调整**：保留灰白环境、黄黑字与传统器物/现代设备的反差，不自动继承人物服装和脸。国风物件需要服务于脚本中的知识、整理或专家经验。

- **延展 A「书房数字助手」**：书卷、桌案和笔记本协同组织任务，橙黄重点表现本期成果。
- **延展 B「水墨知识地图」**：将内容关系表现为水墨路径与清晰的数字资料卡，少量黄色标记指向重点。

**无人物 / 竖版**：书卷、砚台、扇或设备承接人物，排除人像与手。竖版上文下物，避免多件国风道具挤压标题。

### R13-09 · 白底产品聚焦

**原图观察**：大面积白底，左右黄色黑描边大字；中心人物在笔记本后方，屏幕里有橙色三维产品对象；装饰少，主对象与短标题直观。

**保留与调整**：保留白底、少量黄黑大字、一个主产品与一个辅助对象。原图写「开源」不表示本期产品开源，文案仍以用户标题与脚本为准。

- **延展 A「单产品发布」**：产品放大居中，少量短字围绕它；本期最关键的一项用途由一个物件或界面表达。
- **延展 B「成果卡聚焦」**：主对象改为本期生成的成果，设备退为辅助，用留白体现简洁。

**无人物 / 竖版**：放大笔记本、产品或成果卡，不保留半张脸；竖版标题在上、主对象下，不把横版左右大字机械挤到两边。与 B05-A/B 相近。

### R13-10 · 微缩岛屿世界

**原图观察**：蓝色背景，前景漂浮的草地岩石岛；左侧微缩房屋，右侧巨大人物头部；现实与微缩尺度混合，封面内没有明显大标题。大小反差本身成为焦点。

**保留与调整**：保留悬浮剖面、微缩空间与尺度差，不沿用人脸。本期需要标题时，按用户标题加入清楚的文字区，不以原图少字为由省掉要求。

- **延展 A「知识库岛屿」**：资料、检索入口与成果成为岛屿中的建筑或区域，以路径表达脚本关系。
- **延展 B「工作流微缩工厂」**：输入、处理、输出成为少量连续车间，放大一个关键设备突出本期任务。

**无人物 / 竖版**：用放大的产品、资料库或设备代替巨大头像；竖版顶部标题，岛屿置中下，减少房屋数量，保留尺度对比。

## 使用与验图规则

1. 根据脚本选一个参考项和一个延展方向；用户指定时直接沿用。默认适度延展，保留两三项识别特征，改变一个主要维度，不自动混合所有场景。
2. 原图传入提示词时标明位置，例如：「R13 第二行第 2 张是唯一风格参考，其他九张不是参考。输出一张独立封面，不能生成截图、列表或拼图。」
3. 原标题、人物身份、型号、作者名字，以及播放量、评论数、时长、截图边框全部与风格拆开。输出本期标题，不复制平台信息。
4. 无人物默认排除真人、虚拟人、脸、肖像和人形剪影。非人形动物或表情角色也不自动加入；用户要求只有产品和界面时一并排除。不能用机械人脸规避无人物要求。
5. 横竖版分别构图。验图时检查延展是否仍保留所选风格、主视觉是否表达脚本、文字是否正确，以及无人物和画幅是否满足。
