# Video CoverCraft 真实生图案例

以下 6 张封面由 Codex 内置图片工具实际生成，覆盖五种基础风格与一种参考延展；3 张有人物、3 张无人物，横竖版各 3 张。人物为原创虚拟角色，软件界面为示意设计。

每种风格均可选择有人物或无人物，本页标注的是这些样张的具体设置。图片保留工具返回的 PNG，未补绘或替换文字。

## 01 · B01 黄蓝冲击

**原创虚拟人物 · 16:9 · 1672 × 941px**

![B01 黄蓝冲击，原创虚拟人物，16:9](images/01-yellow-blue-presenter.png)

输入：视频演示把零散想法整理成任务计划，再交给 AI 协助完成草稿；封面用人物和设备展示工作搭档的概念，不作效率倍数承诺。

主标题：AI / 工作搭档；副标题：从想法到成品。

设计：借鉴九宫格第二行左侧的标题轮廓与黄蓝视觉，把内容延展为 AI 工作搭档，重新组织横版设备和任务卡。

## 02 · B02 蓝黑科技

**无人物 · 3:4 · 1086 × 1448px**

![B02 蓝黑科技，无人物，3:4](images/02-blue-tech-no-person.png)

输入：根据原视频脚本的核心关系，先讨论功能范围和验收标准，再交接开发说明，最后实现与测试。不承诺具体额度节省比例。

主标题：先聊清楚 / 再开发；副标题：ChatGPT → Codex。

设计：借鉴 R10 的深色设备空间与白青标题，以聊天面板、文档和电脑承接无人物主视觉。
