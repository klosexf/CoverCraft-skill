# CoverCraft 2.6.0 · 封面工坊（优先 GPT Image）

根据**视频脚本、视频描述或封面描述**生成封面，任一种输入都可以，也可组合；支持横版、竖版和可选人物。主流程是：**理解已有内容或画面要求 → 采用或拟写标题 → 确认画幅与人物 → 分析参考与延展 → 选择配色 → 选择生图通道并生成 → 验图与修改 → 导出**。

你可以提供完整脚本，也可以只说明视频讲什么，或者直接描述想要的主体、场景、构图、文字和配色。描述已足够时，不要求补交完整脚本。标题和参考图都是可选的：明确指定的标题逐字采用，未提供时根据已有内容拟写；要求无字封面时不加文字。

生图前会先问「要横屏还是竖屏？」「需要有人物还是无人物？」。三种输入都适用，已经说清的选择不重复问；也可以明确授权这两项由 Agent 决定。选择有人物并不要求本人出镜，可用指定照片或原创虚拟角色。

## 三种输入方式

| 你提供什么 | Skill 怎么处理 |
| --- | --- |
| 视频脚本 | 提炼核心内容、方法与关键关系，确定标题和主视觉 |
| 视频描述 | 根据选题或内容简介生成，不要求完整脚本 |
| 封面描述 | 直接落实主体、场景、构图、文字、配色和风格要求，可以没有视频内容 |

多种输入一起提供时，结合内容事实和你的画面要求；没有指定的细节可以自主延展。纯画面描述不会被扩写成虚构的视频内容，视频标题允许留空。只有描述太空泛、缺少核心主题或画面意图，或输入存在实质矛盾时，才补问关键问题。处理细则见 [输入与标题处理](references/script-to-cover.md)。

默认优先 GPT Image；当前平台没有可用的 GPT Image 时，使用该平台自带的生图工具。选定工具生成整张封面和中文标题；HTML 用于查看结果。参考图提供视觉方向，场景、构图与配色可以根据本期内容延展。

## 跨平台生图顺序

1. 当前平台有可调用的 GPT Image，优先使用。
2. 没有可用的 GPT Image，自动调用平台自带的生图工具，说明实际通道。
3. 用户可以自行配置并明确选择 OpenAI 图片 API；该选择优先于默认顺序，仅存在 Key 不会自动启用 API。

平台没有任何可用生图工具、也没有选定的可用 API 时，会说明缺少能力并提供设计草案。Skill 不会替平台凭空增加工具；能读取 Skill、查看并传入参考图、调用生图工具的 Agent 才能执行完整流程。聊天模型与生图模型分别识别，未知型号不会猜成 GPT Image。

API 路径、环境变量、依赖与运行示例见 [OpenAI API 配置说明](references/openai-api-setup.md)。其他支持本地脚本的宿主可使用包内的官方 SDK 助手；Codex 优先使用其维护的 API 客户端。用户指定“只用 GPT Image，不要回退”时遵从该限制。

## 其他已支持的能力

1. **视频标题与封面文案分开**：视频标题交代内容，封面突出痛点或方法。明确给出的封面文字逐字保留；只提供未区分用途的“标题”时仍作为封面标题，不自动缩写。
2. **风格自由组合**：构图、配色、质感、字形、情绪强度、文字密度分别选择，可把基础结构延展成纸雕、摄影、漫画等一致的组合。扩展为十种 AI 基础风格、30 个分支，保留 31 个原参考项。
3. **账号偏好与系列模板**：记住你明确要求长期沿用的规则，当次要求优先。默认配置允许自主选择配色，画幅和人物未预设；只有明确的长期要求才会保存。
4. **列表预览**：浅/深色背景、320/168/120px 小图、模拟时长和点赞遮挡、边缘裁切及周边示例卡片。预览不修改图片；模拟界面不是平台规范。
5. **中文专项验收**：逐项核对主副标题、品牌、流程标签、数字及背景杂字，记录未核验和需要修正的项目。依赖实际看图，不保证首图零错字。

细则见 [标题处理](references/script-to-cover.md)、[设计维度](references/design-dimensions.md)、[账号偏好](references/account-preferences.md) 和 [文字与预览验收](references/text-and-preview-review.md)。

## 使用条件

- 支持提供所需工具的 Agent 宿主；Codex 的内置 GPT Image 通道不需要另配 API Key。
- 内置通道的具体模型版本由宿主控制，技能不能通过不存在的参数锁定型号。
- 可选 API 使用用户指定的 GPT Image 型号和支持参数，不硬编码最新型号。参考 [OpenAI 图片 API 指南](https://developers.openai.com/api/docs/guides/image-generation)。
- 平台原生工具的参数、参考输入、编辑与尺寸能力以实际工具说明为准，不能照搬 Codex 参数；生图能力缺失时如实说明。
- 导出助手可选，需要 Python 3.9+ 和 Pillow；生图本身不依赖导出助手。
- 列表预览助手同样使用 Python 3.9+ 和 Pillow；页面本身可离线查看，无需额外服务。

## 安装

解压包，进入 `cover-craft` 文件夹，运行：

```bash
python3 scripts/install_skill.py --target codex
```

默认安装到 `${CODEX_HOME:-~/.codex}/skills/cover-craft/`。也可用 `--destination /absolute/skill-root` 指定技能目录，例如 `~/.agents/skills`。一次只安装到一个技能根目录，避免同名版本重复。

其他平台请按其 Skill 导入方式放入完整的 `cover-craft` 文件夹；`SKILL.md` 是入口，参考文档、原图和脚本一并保留，不只复制一个提示词文件。这个安装助手默认目标是 Codex，不假定其他平台采用相同发现目录。

已有同名技能时，默认拒绝覆盖。确需替换可用 `--replace`，原目录会先保留在技能根目录旁边的 `skill-backups/cover-craft/` 中，避免备份被误发现为另一个 Skill。安装后重新加载会话；安装不会为旧会话凭空增加缺失的图片工具。

替换安装时保留原有 `user-preferences.json`，不会用新版默认配置覆盖个人设置。以后可直接说“记住，这个系列沿用大标题和设备场景，配色你决定”；一次性的“这张选 A”只影响本期。

## 调用

可以粘贴或附上完整脚本，不必先整理摘要：

```text
$cover-craft
请根据下面的视频脚本制作封面，沿用内置 R10 的蓝黑软件教程风格。
我没有想好标题，请帮我拟写。
生图前先问我横屏还是竖屏、有人物还是无人物。

视频脚本：
（在这里粘贴你的完整脚本）
```

也可以附上参考图，并一次给全标题和选择：

```text
$cover-craft
参考这张图的构图、配色和中文大标题。
主题：AI 自动剪辑完整工作流。
主标题：AI 自动剪辑；副标题：完整工作流。
不放人物，横版 16:9 和竖版 3:4 各一张，用 GPT Image 生图。
```

也可以只给视频描述：

```text
$cover-craft
视频描述：教大家先在 ChatGPT 聊清楚开发需求，再交给 Codex 实现。
做一张竖版 3:4，无人物，标题请帮我拟写。
用文档和电脑表达两工具接力，配色你决定。
```

或者只给封面描述：

```text
$cover-craft
封面描述：一张深青与暖橙配色的竖版 3:4 封面，无人物。
上方大字「省额度小技巧」，左侧聊天面板，中央开发说明，右下方电脑。
用一道发光箭头连接三个对象，背景像温暖的书房。
按这个画面要求生成一张，不需要我补视频脚本。
```

人物也可选上传照片或原创虚拟角色，无需必须本人出镜。多张参考可以分别指定风格、构图、照片和软件素材的角色。更多调用示例见 [使用示例](references/examples.md)。

## 这组参考图已内置

最初 11 个附件中的第 7、8、11 张是相同九宫格，共 9 张唯一原图、17 个参考项。后来追加的两张横版拼图共含 14 张封面，已逐张提炼。全库保存 **11 张未改动的原图、31 个可单独调用的参考档案**，不把拼图当成已裁出的清晰单图。

以后可直接说「沿用内置 R10 的蓝黑软件教程风格」或「参考九宫格第二行左侧的黄蓝大标题」。Skill 会查看并把所选原图传给选定生图工具，不需要每次重新上传这组图。原图中的真人默认只作为风格参考，使用人物照片需你另行选择。

## 基础风格与延展

共 **10 种 AI 基础风格**：黄蓝冲击、蓝黑科技、白橙清单、彩色漫画、极简编辑、发布会实测、双阵营对比、未来办公、矩阵控制室、立体概念。每种有三个构图/场景分支，共 **30 个**。默认案例围绕 AI，不主动拓展到美食、旅行、手作、空间改造或电影选题。见 [基础风格目录](references/style-catalog.md)。

这次扩展也分析了 YouTube 的 Matt Wolfe、The AI Advantage，以及哔哩哔哩 AI超元域的实际封面，提炼大标题、对象尺度、比较关系、人物与无人物的组织方式。观察与设计建议分别记录，见 [网上封面调研与来源](references/ai-creator-cover-research.md)。网上样本另计，不改变内置原参考数量。

[原参考档案](references/user-reference-library.md) 的 17 项和 [新增横版档案](references/horizontal-reference-library.md) 的 14 项分别有两种延展建议。新增项包括深色发布会实测、冷暖双阵营对比、勾叉观点辨析、产品实测问答、太空夸张体验、多臂工作助理、魔法入门教程、航海全解教程、矩阵控制室、云端理想世界、未来悬浮办公、国风专家模式、白底产品聚焦、微缩岛屿世界；都有无人物与竖版适配方法。

这些数量含义不同：10 是基础风格，30 是基础分支，31 是原参考项；它们可能相近，不相加成风格总数。未指定具体分支时会按本期内容与画面要求选择，默认适度延展；只要一张时只做一张。

## 配色可以自主变化

基础名称和原图颜色都是起点，可以根据已有内容、画面要求、主视觉和可读性改色，借鉴网上搭配后再调整。用户明确指定品牌色或某组颜色时才锁定。无需增加第三个必须回答的配色问题。

已加入午夜橙蓝、电光紫青、柠檬紫墨、晨雾薄荷、深绿暖金、靛蓝蜜桃、奶油莓果、海盐糖果八组起点，另可继续创作。后三组保留公开色卡的作者与来源；见 [配色方法与来源](references/color-palettes.md) 和 [配色色卡预览](palette-preview.html)。色卡不是生图样张，最终可读性仍检查实际成图。

```text
$cover-craft
参考 R12-02 冷暖双阵营对比，延展成两工具接力。
请根据我提供的视频脚本做一张竖版 3:4，无人物。
没有标题，请帮我拟写；配色你决定，可借鉴网上好看的搭配。
```

## 输出与限制

真实生成的原图、PNG/JPEG 导出、缩略图与对比预览，以及设计摘要和实际使用的提示词。只有比例相符时进行等比尺寸调整；横竖版由模型分别构图。不会把一张拼图冒充多个独立方案。

AI 成图默认是扁平图片，不附带自动分层源文件；要求独立可编辑文字时可选择额外排版。中文标题与身份仍需生成后检查，不能保证每次首图就正确。

内置参考库提供可复用的视觉档案与原图；封面主体、文案和场景根据当前制作要求重新设计。
