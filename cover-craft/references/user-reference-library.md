# 用户这组参考图：原图与特征档案

本页分析最初一组真实参考：11 个附件包含 9 张唯一图片，第 7、8、11 张字节相同，共用 R07。它们提炼为 17 个参考项。后来追加的两张横版拼图包含 14 项，见 [新增横版档案](horizontal-reference-library.md)；全库合计 13 个附件、11 张未改动的原图、31 个参考项。编号、位置与哈希见 [assets/reference-manifest.json](../assets/reference-manifest.json)。

**使用时查看所选原图，再把该原图作为选定生图工具的参考输入。** 不只读此文的文字描述。路径相对于 Skill 根目录；调用工具需转成当前安装位置下的绝对路径。内置图都只有风格参考角色，图中的真人不是已选择的身份素材。

用户新提供的参考与要求优先。本库仅提供可沿用的视觉语言，不强制所有新选题使用某个场景或色彩。表中的延展是本技能的设计提议，不是原图观察；各项给出两个方向，可按脚本单独调用。基础风格见 [style-catalog.md](style-catalog.md)；配色允许自主延展，见 [color-palettes.md](color-palettes.md)。

用户选择某格时，将 R07 原图传给模型，并在提示词中指定对应行列：**仅使用该格的视觉语言，其他格不是本次参考；输出一张独立封面，不生成九宫格，不复制周围边框。** 如果像素过小影响观察，可请求单张清晰原图或通过支持图像输入的生图工具得到供后续使用的局部参考；不要声称手上已有清晰原始封面。

无人物版借用该格的色彩、标题字形与信息层级，把人物动作转成产品、设备或箭头的视觉方向。访谈照片是事件内容而不仅是风格；如果用户实际要做访谈封面且需展示嘉宾，使用其指定的嘉宾素材。

## 所有原图共同的排除项

- 底部爱心、点赞数字、截图边框、底栏和播放控件属于平台界面，不作为封面设计继承。
- 参考标题中的品牌、模型版本与数字只是该图的原文案，不是当前事实，也不是本期必须写的文字。
- 图中的人脸、作者名字、水印和账号标记不因用户选择同风格而被自动沿用。
