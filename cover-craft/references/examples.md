# 使用示例

## 只有视频描述，无完整脚本

```text
$cover-craft
视频描述：演示先在 ChatGPT 讨论记账工具的需求，整理开发说明，再交给 Codex 开发与测试。
目的是有机会减少反复澄清和重写，不承诺具体省多少额度。
竖版 3:4，无人物；标题请拟写，配色自由选择，只做一张。
```

从这段简介提炼“讨论 → 开发说明 → 实现”的关系即可，不索取完整脚本；画幅和人物已明确，直接使用推荐文案继续。

## 只有封面描述，无视频内容

```text
$cover-craft
封面描述：竖版 3:4，无人物；深青书房背景，暖橙光照着右下方笔记本电脑。
左侧浮起一块聊天面板，中央一张开发说明，用发光箭头连接到电脑。
上方主标题逐字写「Codex额度用太快？」；副标题逐字写「省额度小技巧」。
主体清楚，标题很大，只生成一张。
```

直接按画面要求生成，不要求脚本或视频简介；指定标题逐字采用，不自行增加节省比例或其他宣传词。

## 封面描述，明确无字

```text
$cover-craft
做一张横版 16:9、无人物、无文字的封面。
画面只有漂浮文档、一台笔记本电脑与连接它们的柔和光线。
奶油白与薄荷青，纸雕质感，留出左上方空白，不加品牌与数字。
```

不拟图中文字，也不自动填满指定留白；无视频主题时视频标题可留空。

## 视频内容与封面描述一起提供

```text
$cover-craft
视频描述：如何先明确需求，再开始开发，减少反复修改。
封面描述：用两块软件面板和中央文档表达先后接力，竖版 3:4、无人物。
主标题用「先聊清楚，再开发」，延续 R12-02 的冷暖分区，但不要做性能对决。
```

内容描述约束主视觉关系，封面描述确定构图和文字，参考补充视觉语言；参考里的人物不影响本期无人物选择。

## 默认的跨平台顺序

```text
$cover-craft
根据脚本和内置参考做一张竖版 3:4、无人物封面。
优先使用 GPT Image；平台没有可用的 GPT Image 时，直接用平台自带的生图工具。
请说明实际通道，完成中文检查和列表预览。
```

如果用户只说“用 GPT Image”，按默认偏好处理；明确说“只用 GPT Image，不要回退”时才限制通道。下面仍有一些 GPT Image 偏好的示例，其内容与验收规则同样用于平台原生通道。

## 使用自行配置的 OpenAI API

```text
$cover-craft
本期使用我已在本地配置的 OpenAI 图片 API，使用我配置的 GPT Image 型号。
参考 R10，根据脚本做一张竖版 3:4、无人物封面。
标题请拟写；不要自动换型号，完成中文检查和列表预览。
```

配置见 [openai-api-setup.md](openai-api-setup.md)。用户明确说“以后默认使用我的 OpenAI 图片 API”时可保存持续偏好；单独设置环境变量 Key 不改变默认选择顺序。

## 分别提供视频标题与封面文字

```text
$cover-craft
视频标题：Codex 省额度小技巧：先在 ChatGPT 聊清楚方案。
封面主标题逐字采用：Codex额度用太快？
封面副标题逐字采用：省额度小技巧。
脚本讲先讨论功能范围、关键决定和验收标准，再交给 Codex 开发。
竖版 3:4，无人物，只做一张；配色自由延展。
检查所有中文与背景杂字，并提供列表预览。
```

## 设置长期系列偏好

```text
$cover-craft
记住：我的“AI 实用教程”系列保持大标题和设备场景，配色你决定。
以后这个系列默认竖版 3:4、无人物，这两项不用再问；本期明确指定时按本期要求。
```

这个明确的持续授权可写进账号文件的对应系列；其他系列和未设置的默认值仍按当前任务处理。“这张选 A”不会自动写成长期偏好。

## 组合设计维度

```text
$cover-craft
沿用 B03 的任务卡层级，质感用纸雕，配色自由选择，标题用清楚的粗黑体。
脚本讲整理需求后再开发；视频标题和封面短文案请分别拟写。
横版 16:9，无人物，一张；GPT Image 生图后核对文字并提供列表预览。
```

这些文字可直接交给装有本技能的 Agent。内置参考按编号直接选择，不需重新上传；其他参考或人物照片需同时附图或提供可读取的本地路径。

## 只有脚本，没有标题

```text
$cover-craft
根据下面的视频脚本做封面，我没有标题，请帮我拟写。
可以参考内置 R10 的蓝黑软件教程风格。
生图前先问我横屏还是竖屏、有人物还是无人物。

脚本：
今天演示把一段口播素材交给 Agent 剪辑的流程。
先导入视频并完成转写，再根据脚本删掉停顿和重复句，最后检查并导出成片。
```

Skill 会先提炼核心内容、给出推荐标题，再询问两项选择，等回答后才生图。

## 脚本与标题都已提供

```text
$cover-craft
标题：从脚本到成片。
请采用这个标题，根据我附上的脚本文件生成相应封面。
生图前先问我画幅和是否有人物。
```

Skill 优先采用给出的标题，同时用脚本确定画面的关键对象与关系。

## 参考图 + 无人物 + 双画幅

```text
$cover-craft
参考我附的第1张图的配色、大标题、主体大小和背景光效。
主题：AI 自动剪辑完整工作流。
主标题：AI 自动剪辑；副标题：完整工作流。
不放人物，用软件界面和笔记本作为主视觉。
用 GPT Image 生图，横版 16:9 和竖版 3:4 各做一张。
不要沿用参考图的原文案、作者名字或点赞界面。
```

## 参考风格 + 可选出镜照片

```text
$cover-craft
第1张是风格参考，第2张是我选择的人物照片，第3张是软件素材。
只参考第1张的构图、标题层级和色彩，不沿用其中人物的脸。
主题：三个工具跑通剪辑工作流。封面主标题：自动剪辑全流程。
使用第2张的人物，用 GPT Image 做一张 16:9 横版封面。
```

## 漫画参考 + 原创角色

```text
$cover-craft
参考附图的粗线条、网点纹理和标题断行。
主标题：Codex 不顺手？副标题：试试这 10 招。
使用原创插画角色，不用真人照片。
GPT Image 生图，竖版 3:4，做三个不同构思，每个单独出图。
```

## 多图选择与定点修改

```text
$cover-craft
从我给的参考图中挑最适合软件教程的一种视觉方向。
无人物，只做一张 16:9，标题逐字使用「AI 自动剪辑」。
```

后续可说：

```text
只把这张成图的副标题改为「完整工作流」。
继续用 GPT Image 编辑，保持主标题、设备、背景、配色和画幅。
```

## 自主决定

```text
$cover-craft
用 GPT Image 参考我附的封面，做「AI 自动做封面」这个主题。
横屏 16:9、无人物，三个构思你决定，直接做。
```

这里已明确两项选择，直接生成三张独立横版封面。没有明确画幅和人物时，先询问两项；只有明确说这两项也由 Agent 决定且无需询问，才可跳过。

## 新增横版参考，延展成无人物竖版

```text
$cover-craft
参考 R12-02「冷暖双阵营对比」，用「两工具接力」延展。
主标题：先聊清楚，再开发。
脚本讲先在 ChatGPT 确定功能范围、取舍和验收标准，再交给 Codex 实现与测试。
做一张竖版 3:4，无人物。两工具是先后接力，不是性能对决。
配色你决定，可借鉴网上好看的搭配；用 GPT Image 实际生图。
```

可从 R12-02 保留对照光域与粗标题，改用文档和设备体现接力。标题与脚本已给出，画幅与人物明确，直接生成一张，不追加风格或配色批准步骤。

## 基础风格也延展

```text
$cover-craft
用 B03 白橙清单的 B03-A「功能选购架」结构，根据下面的脚本做封面。
竖版 3:4，无人物；标题没想好，请拟一个。
保持浅底、清楚图标与任务层级，配色可换成薄荷青或其他更合适的搭配。
只做一张，用 GPT Image。
脚本：今天比较资料整理工具的检索、标签和导出能力，重点讲按自己的使用场景挑功能。
```

基础名字不是颜色锁定。可采用 P04 晨雾薄荷，但主视觉关系必须来自脚本；不因为目录有三种分支就生成三张。

## 从创意场景中选一个延展

```text
$cover-craft
参考 R13-10「微缩岛屿世界」，延展为「知识库岛屿」。
主标题：资料终于找得到。
脚本讲把分散资料归档到知识库，通过分类和检索找到需要的内容。
横版 16:9，无人物；把入口、分类区与资料库组织成小岛上的空间。
颜色自行延展，保持标题清楚、主体突出；不要原图中的巨大头像。
```

这里采用场景比喻，内容对象和标题来自本期；原截图中的房屋与脸不是必须保留的对象。

## 不知道风格时先看真实样图

```text
$cover-craft
视频描述：教大家把重复操作交给 AI 自动化。
先给我看三种适合的风格，我选完你再生成。
竖版，无人物。
```

展示 B02/B06/B05 的真实缩略图及简短理由，链接全部十种菜单；等待选编号或“你决定”，不在展示菜单时调用生图工具。用户回复“第二张”时按本轮顺序解释为 B06。

```text
$cover-craft
我只想看看你有哪些封面风格，先不要生成。
```

直接展示完整图文菜单，不要求视频脚本、人物照片或画幅。十种风格均可做横竖版与人物开关，不能因主样图有女性人物就把此风格锁成女性/有人物。
